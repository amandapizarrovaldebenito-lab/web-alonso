# Google Search Console Setup

## Property and verification

1. Create a **Domain property** for `alonsopizarro.cl` in Google Search Console.
2. Copy the TXT verification value generated by Search Console.
3. Add that TXT record at the authoritative DNS provider for the apex domain.
4. Keep the TXT record in DNS after verification.

No verification meta tag or fictitious DNS token has been added to this repository.

## Sitemap submission

After the apex-domain deployment is live and HTTPS is valid:

1. Open **Indexing → Sitemaps**.
2. Submit `https://alonsopizarro.cl/sitemap.xml`.
3. Confirm that Search Console reads exactly seven canonical URLs and reports no parsing error.

## URL inspection checklist

Inspect and request indexing for:

1. `https://alonsopizarro.cl/`
2. `https://alonsopizarro.cl/research/`
3. `https://alonsopizarro.cl/projects/`
4. `https://alonsopizarro.cl/projects/flood-resilience/`
5. `https://alonsopizarro.cl/students-collaborators/`
6. `https://alonsopizarro.cl/teaching/`
7. `https://alonsopizarro.cl/contact/`

For every URL, verify:

- URL is available to Google.
- Indexing is allowed.
- User-declared canonical and Google-selected canonical match.
- Fetched page and screenshot correspond to the intended route.
- Structured data is detected without critical errors.

## Post-launch monitoring

- Review Page indexing for duplicate/canonical anomalies.
- Check HTTPS and Core Web Vitals reports.
- Monitor 404s and redirect errors after server-side 301 rules are activated.
- Use Links and Performance reports to identify real legacy URLs before adding any additional redirect.
- Do not redirect unrelated or unknown old URLs to the home page.
